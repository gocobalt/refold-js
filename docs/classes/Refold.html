    connect

    • connect(params: ConnectParams): Promise<boolean>

      Connects the specified application using the provided authentication type and optional auth data.

      Parameters

      • params: ConnectParams

        The parameters for connecting the application.

        • OptionalautoClose?: boolean

          Whether to close the authentication window automatically.

        • OptionalgrantType?: GrantType

          The application's OAuth grant (from the app object). It no longer selects the transport — every connect is a POST and the server decides — but it still routes: Refold.connect sends a payload-bearing connect down the OAuth path rather than the key-based one when this names GrantType.ClientCredentials and no type was given. Pass type explicitly and it is not needed.

        • Optionalpayload?: Record<string, string>

          The key value pairs of auth data.

        • slug: string

          The application slug.

        • Optionaltimeout?: number

          Maximum time in milliseconds to wait for authentication before giving up. Set to 0 to wait indefinitely. Defaults to 5 minutes.

        • Optionaltype?: AuthType | ConnectorAuthType

          The authentication type to use — an AuthType for native applications, or one of a universal connector's own types (a key of Application.auth_type_options). If not provided, it defaults to keybased when a payload is given, otherwise oauth2.

      Returns Promise<boolean>

      A promise that resolves to true if the connection was successful, otherwise false.

      Throws

      Throws an error if the authentication type is invalid or the connection fails.
